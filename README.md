# JUGUETI PLANET 🚀

Sitio web académico de una juguetería infantil, diseñado con una experiencia visual alegre, colorida y muy interactiva.

## 5 páginas exactas
1. index.html — Inicio
2. nosotros.html — Nosotros
3. coleccion.html — Juguetes
4. aventura.html — Aventura
5. contacto.html — Contacto

## Interactividad
- Animaciones y elementos flotantes.
- Aparición al hacer scroll.
- Barra de progreso.
- Modo oscuro.
- Carrito con contador.
- Favoritos.
- Filtros de productos.
- Selector de aventuras.
- Mini juego de 5 estrellas.
- Contadores animados.
- Formulario validado con JavaScript.
- Diseño responsive.
